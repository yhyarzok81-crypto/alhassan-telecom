# مشروع الحسن للاتصالات — دليل التشغيل من الهاتف

هذا مشروع أولي قابل للتشغيل لمتجر عرض منتجات عربي، مع تصميم أسود وذهبي، بحث وأقسام، سلة استفسار ترسل إلى واتساب، ولوحة مالك لإدارة المنتجات والإحصائيات والطلبات.

## قبل البدء: ما الذي تحتاجه؟

- حساب مجاني على Supabase لقاعدة البيانات وتسجيل الدخول وتخزين الصور.
- حساب GitHub وCloudflare Pages لنشر واجهة الموقع من الهاتف.
- لا تضع كلمة مرور المالك أو مفتاح `service_role` داخل الكود.
- رقم واتساب الافتراضي مضبوط على الرقم السوري `0937532026` بصيغة دولية `963937532026`. اختبره قبل نشر الموقع.

## 1) إنشاء قاعدة البيانات

1. افتح https://supabase.com/ وسجّل الدخول.
2. أنشئ مشروعًا جديدًا واحفظ كلمة مرور قاعدة البيانات في مكان آمن.
3. من القائمة افتح **SQL Editor** ثم **New query**.
4. افتح الملف `supabase/schema.sql` من ملفات المشروع، وانسخ محتواه كاملًا إلى محرر SQL ثم اضغط **Run**.
5. من **Project Settings → API** انسخ **Project URL** و**Publishable key** (أو anon key القديم إن كان هو الظاهر في مشروعك). لا تستخدم `service_role` أو `secret key` في الواجهة.

## 2) إنشاء حساب المالك الوحيد

1. من Supabase افتح **Authentication → Users**.
2. أنشئ مستخدمًا بالبريد الإلكتروني الذي تملكه وكلمة مرور قوية. إذا كان زر إضافة المستخدم غير ظاهر، استخدم خيار إنشاء مستخدم من لوحة Authentication المتاح في مشروعك.
3. افتح المستخدم وانسخ قيمة **User UID**.
4. افتح **SQL Editor** وشغّل الاستعلام التالي بعد استبدال `ضع-UUID-هنا` بالـ UID الحقيقي:

```sql
insert into public.admins (user_id)
values ('ضع-UUID-هنا')
on conflict (user_id) do nothing;
```

5. لا تضف أي مستخدم آخر إلى جدول `admins`. صفحة الموقع لا تحتوي على تسجيل مدير عام؛ الدخول بالبريد وكلمة المرور فقط.

## 3) إعداد مفاتيح الواجهة

1. انسخ ملف `.env.example` وسمّ النسخة `.env` (في GitHub يمكن إدخال القيم في إعدادات البناء بدل رفع الملف).
2. ضع رابط Supabase في `VITE_SUPABASE_URL`.
3. ضع الـ Publishable/anon key في `VITE_SUPABASE_ANON_KEY`.
4. ضع رقم واتساب الدولي دون علامة `+` أو مسافات في `VITE_WHATSAPP_NUMBER`. مثال: `963937532026`.
5. لا ترفع ملف `.env` الذي يحتوي على أي أسرار إلى مستودع عام. الـ Publishable/anon key مصمم للاستخدام من الواجهة مع سياسات RLS الصحيحة، أما `service_role` فممنوع وضعه في الواجهة.

## 4) التشغيل محليًا

يتطلب تشغيل أوامر Node.js بيئة فيها Node.js وnpm. على أندرويد فقط قد تكون هذه الخطوة غير مريحة؛ لذلك يُفضّل استخدام GitHub مع Cloudflare Pages للبناء والنشر من المتصفح.

```bash
npm install
npm run dev
```

## 5) النشر من الهاتف باستخدام GitHub وCloudflare Pages

1. أنشئ مستودعًا جديدًا في https://github.com/ وارفع ملفات المشروع إليه.
2. افتح https://dash.cloudflare.com/ ثم **Workers & Pages → Create → Pages → Connect to Git**.
3. اختر مستودع GitHub الخاص بالمشروع.
4. إعدادات البناء:
   - Build command: `npm run build`
   - Build output directory: `dist`
5. في إعدادات المشروع، أضف متغيرات البيئة:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - `VITE_WHATSAPP_NUMBER`
6. ابدأ النشر، وافتح رابط `pages.dev` الذي تحصل عليه.
7. جرّب الموقع من نافذة خاصة: يجب أن يرى الزائر المنتجات النشطة، وألا يستطيع تعديلها. جرّب تسجيل دخول المالك من زر «دخول المالك».

## 6) ملاحظات مهمة قبل الاستخدام الفعلي

- **النسخ الاحتياطي:** صدّر المنتجات دوريًا إلى CSV، واحتفظ بنسخة من ملفات المشروع. هذا ليس بديلًا عن نسخة احتياطية كاملة لقاعدة البيانات والصور. اختبر استعادة النسخ قبل الاعتماد على المتجر.
- **حدود الخطة المجانية:** قواعد البيانات والتخزين لها حصص، وقد تتوقف بعض المشاريع المجانية مؤقتًا بعد عدم النشاط. راجع الأسعار الحالية في Supabase وCloudflare قبل الاعتماد التجاري طويل الأمد.
- **طلبات واتساب:** الموقع يسجل أن الزائر جهّز طلب استفسار، ثم يفتح واتساب برسالة جاهزة. لا يستطيع الموقع معرفة أن الرسالة أُرسلت فعلًا أو أن البيع تم. حالة «بيع مؤكد» يحددها المالك يدويًا.
- **السلة متعددة العملات:** إذا جمعت منتجات بعملات مختلفة، فلن يعرض الموقع مجموعًا موحدًا؛ سيطلب تأكيد السعر من المحل.
- **إحصائيات الزوار:** الإحصائيات الحالية تسجل أحداثًا مثل مشاهدة المنتج والضغط على واتساب، ولا تمثل أشخاصًا فريدين، ولا تجمع بصمة الجهاز.
- **المنتجات بعد البيع:** الأفضل جعل الكمية صفرًا أو إخفاء المنتج بدل حذفه؛ الحذف النهائي متاح من لوحة المالك.
- **صور المنتجات:** صور عامة للعرض، لكن سياسات التخزين تمنع غير المالك من الرفع والتعديل والحذف. ارفع صور المنتجات فقط.
- **مميزات تحتاج تطويرًا لاحقًا:** استيراد CSV إلى الموقع، قص الصور داخل لوحة المالك، مقارنة المنتجات، تقييمات الزبائن، تقارير مبيعات مؤكدة، وجدولة نسخ احتياطي آلي. يوجد تصدير CSV في هذه النسخة، لكن الاستيراد غير مفعّل بعد.
- **الأمان:** لا تشارك كلمة مرور المالك أو UUID الخاص بحسابك في المحادثات العامة. اختبر سياسات قاعدة البيانات قبل نشر بيانات حقيقية.
